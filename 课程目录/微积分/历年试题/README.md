## 2025 年秋季微积分Ⅰ期中考试勘误

第五大题的单调性证明应从第二项开始。当 $0<a<1$ 时，$x_2=(a+1)/2>x_1=a$。由均值不等式可得 $x_n\ge\sqrt{a}$（$n\ge2$）。原解的差分式分母漏了系数 $2$，正确式子为

$$
x_{n+1}-x_n=\frac{a-x_n^2}{2x_n}\le0 \qquad(n\ge2).
$$

因此数列从第二项起单调不增且有正下界。设极限为 $L>0$，在递推式中取极限得 $L^2=a$，所以极限仍为 $\sqrt{a}$。[河畔原帖](https://bbs.uestc.edu.cn/forum.php?mod=viewthread&tid=2501960)
