# README 模板索引

`课程目录/0-模板` 是课程 README 与标准分类表格的唯一模板来源。本目录保留原入口文件，以链接指向对应模板，不维护表格副本。

| 类型 | 模板 |
| --- | --- |
| 课程 | [课程 README](../../课程目录/0-模板/README.md) |
| 复习资料 | [复习资料 README](../../课程目录/0-模板/复习资料/README.md) |
| 历年试题 | [历年试题 README](../../课程目录/0-模板/历年试题/README.md) |
| 作业 | [作业 README](../../课程目录/0-模板/作业/README.md) |
| 教材 | [教材说明](教材README模板.md)，尚无统一表格 |

复制课程模板时替换标题、介绍和下载链接中的占位内容；复制分类模板时只保留标题、表头和分隔行，删除示例行。命名、元数据和排序遵循[维护指南](../维护指南.md#readme-更新)。

考研资料使用同一分类表格；科目 README 从课程模板改写，下载路径改为 `考研目录/<科目名>`。工具支持范围见维护指南。
